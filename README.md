# IPPO 会員アプリ

小学生・中学生向けオンラインサッカースクール **IPPO** の会員専用アプリ。
「昨日の自分から、一歩前へ」— 他人との競争ではなく、継続と成長を肯定する。

> **現在の状態: Phase 1（基盤）完了。** ドメイン層・データ層（デモ用）・サービス層の土台とテストまで。
> 会員向けの画面はまだ LP の料金表だけ。計画は [docs/05-フェーズ計画.md](docs/05-フェーズ計画.md)。

## 動かす

```bash
npm install
npm run dev          # 環境変数ゼロでデモモード（インメモリ）で起動
npm run verify       # lint → typecheck → test → build（これが通らないコードは報告しない）
IPPO_SEED=sample npm run dev   # 画面確認用の架空データを入れて起動
```

Node.js 20.9 以上。`.npmrc` の `legacy-peer-deps=true` は npm 10 の依存解決の不具合回避のため（理由はファイル内に記載）。

## デモモードについて（必ず読んでください）

- Supabase の環境変数（`NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY`）が**3つすべて**そろっていないときはデモモードになる。
- デモモードのデータは**サーバーのインスタンスごとのメモリ**にある。
  - 再起動・再デプロイで消える。
  - Vercel のように複数インスタンスで動くと、インスタンス間で共有されない（別のリクエストで別のデータが見えることがある）。
  - 消えて困るものは seed（`src/data/seed/`）に置く。
- seed は2種類。**既定は `empty`**（運営1人とプラン・クラス枠・診断などの定義だけ。架空の子どもは入らない）。
  `IPPO_SEED=sample` のときだけ架空の人物が入る。環境変数の書き忘れで架空の子どものデータが本番に出ないようにするため。
- サンプルの人物はすべて架空（表示名に「サンプル」、本名に「架空」、メールは `@example.invalid`）。実在の子どもの情報は使っていない。

## 正式公開前に専門家の確認が必要な項目

このアプリは以下の法令・規程に**適合していると断定していない**。公開前に弁護士など専門家の確認を受けること。

- [ ] **個人情報保護法**: 取得する項目（本名・メール・年代・提出写真・プレー動画）と利用目的の明示、第三者提供、安全管理措置、開示・削除請求への対応、退会後の保存期間
- [ ] **こどもの個人情報**: 保護者の同意の取り方（誰が・いつ・どの範囲で同意するか）、子ども本人への説明のしかた、写真・動画に本人や他の子が写り込む場合の扱い
- [ ] **特定商取引法**: 月額プランの表示（通信販売の表示事項、解約条件）。決済を実装する段階で改めて確認
- [ ] **資金決済法まわりのポイント**: ポイントが「前払式支払手段」に当たらない設計か（無償付与のみ・現金や商品券と交換しない・有効期限など）、景品表示法上の景品類の扱い
- [ ] **利用規約・プライバシーポリシー**: 未成年の利用、監査対象チャンネル（運営がメッセージを閲覧できること）の明示、YouTube 埋め込み動画はアプリの外でも見られることの明示、禁止事項
- [ ] 外部サービス（Supabase / Mux / Vercel / YouTube）のデータ保存場所と委託先としての扱い

## 未実装・既知の穴（正直な一覧）

Phase 1 時点。解消するフェーズは docs/05 を参照。

| 穴 | 影響 | 解消 |
|---|---|---|
| ログイン・セッション・`src/proxy.ts` が無い | 会員向け画面がまだ無い | Phase 2 |
| **Supabase RLS が無い**（3層のうち3層目） | 本番公開できない。デモモードでのみ動く | Phase 6（完了まで公開しない） |
| Supabase 版 DataStore が無い | 環境変数を3つそろえると「未実装」で止まる（黙って mock にはしない） | Phase 6 |
| 動画再生（署名URL / Mux JWT の発行）が無い | 動画はまだ見られない | Phase 3 |
| Storage のファイル削除（退会時） | 退会しても提出写真・動画のファイルは残る（DB の個人情報は消える） | Phase 6 |
| CSP 未設定 | その他のセキュリティヘッダーは設定済み | Phase 3 |
| Playwright の E2E が0本 | 設定のみ | Phase 2〜 |
| 画面録画・スクリーンショットは技術的に防げない | 有料動画が録画される可能性はある。右クリック禁止などは対策にならない | 運用と規約で扱う |
| ポイント付与の同時実行の保証は mock 実装のみ | 本番は RPC ＋ ロックで保証する設計（docs/02） | Phase 6 |
